# Coral Grapple

This is a configurable Rain World mod that edits grappling worms to allow them to aim in all directions in zero gravity and stick to climbable vines. Unlike Saint's tongue, the act of firing the grappling worm does not give you a speed boost. The mod also has an option to cancel grappling worm use when dropping down a vertical tunnel.
